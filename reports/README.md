# Generated research outputs

This directory contains machine-readable results and generated figures, separated by phase or model family.

- `phase17/` contains Phase 17 preprocessing metadata, fixed split summaries, evaluation JSON, and figures.
- `phase18/` contains the JSON result for each demonstration case and its aggregate summary.
- `pilot/` contains results from the small synthetic claim-verifier pilot.

Human-readable reports and research notes live under `docs/`.
