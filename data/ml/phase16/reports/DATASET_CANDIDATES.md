# Dataset candidates investigated

Search covered academic papers, ACL Anthology, arXiv, GitHub, and Hugging Face; scope included programming factuality, code explanation/QA, code correctness, and general claim-evidence benchmarks. The detailed 19-candidate inventory with all requested fields and explicit decisions is `../candidates/dataset_candidates.csv`.

## Selection result

No public dataset is currently authorized for inclusion. CodeSimpleQA is the strongest lead but its paper contains inconsistent dataset counts, and a public record-level artifact and dataset license could not be verified. It remains REVIEW. Programming QA and code tests have different label units and were not force-mapped.
