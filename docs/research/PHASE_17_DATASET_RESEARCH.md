# Phase 17 — Public dataset research

Research date: 2026-09-27. Repository and environment were inspected before selection. The current CodeGuard review dataset consists of pending proposed labels and synthetic pilot data; it is not a human-verified correctness corpus. No public dataset in this survey is treated as gold CodeGuard data.

## Selection rationale

OpenCodeReasoning-2 is selected for a *narrow auxiliary experiment* because it supplies a substantial Python corpus with a numeric `pass_rate` that is explicitly unavailable (-1) when the source process could not validate it. This offers a more defensible target than treating generated critique as human ground truth. The dataset is not a direct CodeGuard claim-verification dataset. The training target will be an execution-pass-rate estimate, and the user interface/report must call it an auxiliary prediction.

The analysis will preserve upstream `license`, source, dataset, split and question ID fields. It will retain only rows whose license is in the reviewed allow-list, code/question are usable, and pass_rate is in [0,1]. If filtering fails to leave at least 50,000 usable rows, the resulting smaller corpus and reason will be reported; no records will be relabelled to force the target count.
